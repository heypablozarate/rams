# Revisar una interfaz de RAMS

Leé las reglas de interfaz del proyecto y las guías de los componentes RAMS instalados. Empezá por la tarea, su resultado y la señal que permite reconocerlo. Revisá la jerarquía en toda la vista activa: RAMS admite como máximo una acción primaria, incluso con acciones fijas y contenido desplazable.

- Para una decisión visual, usá la biblioteca de diseño que el proyecto reconozca como fuente y compará allí la composición actual con una alternativa que reutilice los controles de RAMS. Comprobá en web el efecto de la decisión. Si sólo hay evidencia del código o del navegador, registrá ese alcance.
- Para decidir si retirar un control, una capa o una frase, recorré la alternativa y comprobá si todavía se entiende qué hacer, qué cambió y cómo recuperarse. Incluí las acciones fijas, las que aparecen al desplazarse y los estados relevantes para la decisión.
- Ordená los hallazgos por cómo afectan la tarea. Para cada uno, indicá estado, observación, impacto y cambio comprobable. Una revisión entrega criterio y evidencia. Aplicá cambios cuando formen parte del pedido.
