# Local form and stock selection

Install proof-label-form for a complete React Hook Form composition. The label must contain 3–32 characters after trimming. Invalid submission focuses the real input and links its help/error; valid submission keeps or updates one local card. Editing or failing validation does not overwrite a previously kept label. The card is page state, not a service save.

Install paper-stock-picker for a controlled query and selected value. Four original fictional worksheet stocks filter by case-insensitive city or stock text. Typing is not committing a selection. Choose an actual option with the keyboard, clear it or inspect the empty state; the complete selected string remains visible beside the narrow input. These are illustrative names/weights, not supplier listings. Neither example sends data, installs a service or persists a record.
