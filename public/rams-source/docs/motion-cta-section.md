# Call-to-action sections

CtaSection supports centered, split, and banner layouts. Actions with href are native links; onClick performs a real callback. An explicit confirmedLabel without either is a local boolean review toggle, exposed with aria-pressed. Actions without any behavior are disabled. The split default is a static original worksheet. onDismiss is called after banner removal; the host owns focus. CtaSectionBlock supplies layout selection plus the single dismissal/restore focus owner and accepts the other section props. No service operation is simulated.
