# Animated text and source

Install the matching motion-* item; use the manifest's complete files and package list. These recipes use CSS Modules and independent Motion. CodeBlock composes CopyButton; disclosure and clipboard controls consume owned Button. Public text inherits Geist and the fluid type roles. Source code uses the system monospace stack and neutral ink; token spans preserve the complete selectable source.

motion-text-reveal presents text as h1/h2/h3/p with a mount entrance and optional delay. Preserve the complete accessible heading while its visual words enter. Delay is in seconds; it does not defer the underlying content.

motion-in-view-title takes text, variant and optional as/lines/once. word, line, blur, tracking and wipe are distinct entrance treatments; lines supplies deliberate breaks for the line style. once defaults to true. Server fallback protects readability when scripts arrive late; a consuming SSR application needs its own hydration verification.

motion-text-morph keeps the supplied string and semantic tag while letters change. Use brief labels, and keep an action's real accessible name outside decorative letter copies. The example changes Ink proof to Paper proof without replacing its focused button.

motion-text-shimmer takes a string, active, optional duration and a semantic tag. active enables the sweep; reduced motion, visibility and page visibility can keep it still. The pause control reports the setting rather than inventing a background task. duration is in seconds and defaults to the shared breathing duration.

motion-code-block takes code, filename, language and optional maxLines. Its header describes the actual snippet; Copy code copies the entire source, including lines outside the collapsed view. Expansion changes only the presentation. The pre remains focusable and may scroll locally for long source lines.

motion-expandable-text takes complete content and a collapsed lines count, controlled expanded/onExpandedChange or defaultExpanded, and optional moreLabel/lessLabel. It shows a toggle only when content overflows. Collapsing retains the full text for assistive technology; links receiving focus are revealed. Keep the complete note in the component rather than substituting a shortened string.

motion-copy-button takes the actual value, label, optional iconOnly/variant/disabled and onCopied. Clipboard access requires a supported secure context and permission. Failure is announced and can be retried; success is announced only after writeText resolves. The latest active request owns feedback; reset or unmount invalidates old feedback and callbacks. The platform clipboard write itself cannot be canceled.

Public examples use original edition references, print notes and CSS. Adapted source and its shared clipboard helper keep ARC's MIT notice; the original models keep RAMS attribution.
