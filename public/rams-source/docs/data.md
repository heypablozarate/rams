# Calendars and charts

Calendar delegates selection and date rules to DayPicker9.14.0. Choose `mode="single"`, `multiple` or `range`, provide selected/onSelect for controlled data, and use disabled/hidden matchers and date bounds when the task requires them. Navigation and dates consume RAMS Button; caption dropdowns consume NativeSelect. Month/year caption dropdowns remain native single-choice controls. Custom classNames are added to the supplied part classes; replacement components receive DayPicker props and must preserve their semantics and refs.

The default caption is a label and outside days are shown. Multiple months wrap when space narrows. A calendar is a two-dimensional date grid: at enlarged text its month may scroll locally rather than shrink date text or overflow the page. Week numbers reserve an eighth column. Native date labels, selected/disabled states and arrow navigation stay with DayPicker. `autoFocus` opts into initial focus; the legacy `initialFocus` alias maps to it, and explicit autoFocus takes precedence. No focus is requested by default.

ChartContainer provides a responsive Recharts frame and scoped series metadata. It does not create data or chart marks. Give the chart a meaningful accessible name, enable the native chart's accessibilityLayer, and choose marks/labels appropriate to the data. The current font supplies real tabular figures; shared numeric styling is used for axis ticks and tooltip values. Color alone must not identify a series: pair it with labels, different traces or meaningful markers.

ChartConfig keys use letters, numbers, underscores and hyphens so each can become `--color-key`. A series accepts a React label, decorative icon, and either color or per-theme light/dark colors. Without an explicit color, the frame uses host chart tokens, falling back to five tonal mixes of the host primary and surface. A `.dark` host selects dark theme values. ChartStyle exposes the same scoped variable generation for a manually named data-chart root. Its id is a simple identifier; colors must be single color values, not stylesheet statements.

ChartTooltip and ChartLegend retain the independent Recharts props. ChartTooltip limits its default wrapper width to the native plotted area after axes; a caller's wrapperStyle can override this limit. Their RAMS content renderers read the nearest frame's config. The tooltip uses RAMS Card, displays configured names and real values, supports hidden label/indicator, label/name metadata keys and dot/line/dashed indicators. Numeric values use English number formatting; a formatter can return a value or [value,name]. Per-entry formatters take precedence; a null result omits the row. Label formatter, value sorting and content/item/label styles remain supported. Accessor-function data keys should supply a name or formatter. With accessibilityLayer, the content retains the native live-status behavior.

Legend content supports configured names/icons, hidden icons, label formatters and native layout/alignment. A supplied click handler gets a keyboard-accessible button for each item. Inactive entries retain readable labels and an inactive cue. The application still owns any visibility/selection state changed by those callbacks.

[Press Window](../examples/press-window.tsx) filters six original weekly sheet records by the selected date window. Solid and dashed traces distinguish folded and flat sheets. Clear dates restores the full dataset; a window without records displays an actual empty state. Selection and records live in React state.
