# Ranges and edition codes

Slider controls one value or an ordered range. Its thumbs are siblings of the track. Give a single slider `aria-label` or `aria-labelledby`; these name the thumb rather than an inert wrapper. `aria-describedby` reaches every thumb. A single `aria-valuetext` describes formatted units. For ranges, provide `thumbLabels` that identify each endpoint; the root receives the group's label. Arrow keys, Home/End, step, orientation, disabled state and form behavior belong to the independent Radix primitive. The composed Slider owns Track/Range/Thumb, so it does not expose `children` or `asChild`.

InputOTP uses a real input over visible character slots. Its default `inputMode` is text because edition codes can contain letters. For digits-only input, set a digit pattern and `inputMode="numeric"` together. Validate required code length before updating the record; `maxLength` caps input length and is not a completion rule. Set `maxLength`, associate a Label with its id, and use a matching number of InputOTPSlot children inside InputOTPGroup. The decorative slots do not replace the input's accessible name. Controlled value, form props, ref and `onComplete` reach the independent input-otp library. Its alternative render callback receives slot data directly; slot helpers are for the children/provider composition.

The [Trim Setup](../examples/trim-setup.tsx) changes an actual print width and crop-window range. The diagram uses those proportions. The form checks all six characters before updating the applied local proof record; clearing the draft returns focus to the input. Applying a code is not authentication or a remote operation. Reloading resets the example.
