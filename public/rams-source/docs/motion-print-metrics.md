# Print metrics

MetricCard compares equal seven-run periods. The worksheets total 1,006 and 820 accepted sheets; `(1006 - 820) / 820` gives the displayed +22.7%. The label names sheets and the window; the readout keeps the number separate from that description. The manifest includes its AnimatedCounter source dependency.

Sparkline plots the seven spoiled-sheet counts 8, 7, 9, 6, 6, 4 and 3 at equal run intervals. The default line uses the accent tone. Its accessible slider and pointer cursor inspect the same labelled points; the latest count is 3 and the first-to-last decrease is 62.5%. Source dimensions define the drawing coordinate system; the plot fits its container. Run labels describe an ordered sequence, not elapsed calendar time.

Gauge normalizes its value within min/max for the visible percentage while preserving the physical range in its meter attributes. The registration example measures 0.18 mm within 0–0.50 mm, so it shows 36%. Its explicit thresholds name within tolerance below 0.25 mm, adjustment from 0.25 mm, and stop/realign from 0.40 mm. Those are semantic states with matching text; the example does not rely on color alone.
