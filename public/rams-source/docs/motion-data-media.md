# Motion data and media

Install the individual recipes from the source manifest. They preserve the retained ARC license alongside the RAMS composition and public foundation roles. No proprietary fonts, personal brand rules or image downloads are included.

- `motion-icon-morph`: decorative state icons. Put the icon in a named action with a pressed state; the icon alone is not an accessible button.
- `motion-json-viewer`: explore nested data, search keys and values, and copy values or paths. The tree has keyboard navigation and a local scroll area for long data.
- `motion-slot-text`: present a changing short number or label. Formatting owns the actual text; rolling cells are hidden from assistive technology, with an optional live announcement.
- `motion-image-compare`: compare two supplied React images or SVGs with a controlled or default divider. Arrow keys step, Home/End expose the extremes, and double-click resets the handle.
- `motion-signature-pad`: draw, undo, redo, replay and export actual pointer strokes. The drawing remains local to the current page. An empty drawing disables export.
- `motion-logo-marquee`: provide your own marks, choose their tone and pause the moving row. Repeated visual copies are hidden from assistive technology. Reduced motion makes the row static.

The public type roles use Geist Sans. Numeric reels use the numeric role, while words preserve interface typography. Ink tool colors are explicit drawing options, separate from the tonal chart palette.
