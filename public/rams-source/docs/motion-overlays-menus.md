# Overlays and menus

Install each motion-* recipe with its manifest closure. Retained ARC engines keep their license; RAMS controls and semantic surface parts compose their triggers, actions and naming. Radix is an independent dependency, not an installation service.

Dialog edits a draft without committing on every keystroke. Its print-title example saves a trimmed, nonempty title of at most48 characters. Cancel, Close, Escape and outside dismissal discard the draft; reopening starts from the saved value. The dialog has an associated title/description and returns focus to its trigger after dismissal.

Drawer presents related controls in a side surface. Paper choices update the visible stock/weight/finish immediately; Done dismisses without rolling back that choice. Its own title names the surface. Keep nested Select interaction separate from drawer dismissal.

Popover attaches short settings to its trigger. The ink-pass example changes the actual SVG layers and total impressions for one or two passes. It remains open while settings change; Done, outside press and Escape dismiss it. Default triggers consume Button; asChild preserves the supplied trigger.

HoverCard adds read-only specifications to the referenced plate on hover or focus. When its content overflows, arrow keys, Page Up/Down and Home/End on the focused trigger scroll the actual preview. Essential information belongs in persistent content too; do not put required actions inside transient hover-only help. Tooltip supplies the short Cut guides description while Crop marks remains the independently named toggle. The toggle updates all four actual corner marks and aria-pressed.

DropdownMenu exposes commands for the current proof: crop guides, ink reversal and reset change the same artwork and status. ContextMenu attaches orientation/margin commands to the plate itself, with pointer and keyboard opening. Selecting a command updates the actual target; menu focus and dismissal remain part of that interaction.

CommandPalette searches five authored records using title, city, process and paper keywords. Selecting a result updates its heading, original mark and specifications together. Empty search and clearing recover the same collection; keyboard selection follows the active result. These are local records, not network results.
