# Print organization

TreeView separates keyboard focus, expansion and selected content. The three-city cabinet contains six plates and 240 reference sheets. Selecting a folder or leaf updates the actual drawings and inventory; collapsing a branch keeps the chosen content.

FilterToolbar combines Place, Process and Paper using AND. Each field has one current value. The same six records produce the result list and sheet total, including an empty result that can be recovered by removing or clearing filters.

SortableDataTable orders the Sheets column numerically. Controlled row selection produces an actual packing slip with selected records, stocks and total sheets; sorting does not change that selection. Narrow screens present rows as labelled cards, with a locally scrollable strip of sorting controls. Wider layouts retain columns.

ReorderableList changes the reading order of four booklet sections. Dragging a handle or pressing Arrow Up/Down changes the actual page ranges and page-block diagram. All orders retain 24 pages. Restore original sequence resets the controlled list.
